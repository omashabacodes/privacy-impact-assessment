# Privacy Impact Assessment (PIA)

## Project Overview

This project demonstrates a Privacy Impact Assessment (PIA) performed to evaluate how personally identifiable information (PII) is collected, processed, stored, shared, and protected within an organization.

The assessment identifies privacy risks and recommends controls to ensure compliance with data protection requirements and security best practices.

---

## Objectives

- Identify Personally Identifiable Information (PII)
- Assess privacy risks
- Evaluate data handling practices
- Improve data protection controls
- Support regulatory compliance

---

## Assessment Scope

The assessment focused on:

- Data Collection Processes
- Data Storage Practices
- Data Sharing Activities
- User Access Controls
- Data Retention Procedures

---

## Methodology

1. Data Inventory Review
2. Information Flow Mapping
3. Privacy Risk Identification
4. Impact Analysis
5. Control Evaluation
6. Remediation Recommendations

---

## Sample Findings

### Finding 1

**Issue:** Sensitive customer information stored without documented retention procedures.

**Risk:** High

**Recommendation:** Implement formal retention and disposal requirements.

---

### Finding 2

**Issue:** Excessive user access to sensitive records.

**Risk:** Medium

**Recommendation:** Apply least privilege principles and periodic access reviews.
